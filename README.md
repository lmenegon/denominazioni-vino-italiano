# Denominazioni del vino italiano (DOCG, DOC, IGT)

Tutte le denominazioni del vino italiano, regione per regione, dagli elenchi ufficiali del Ministero dell'agricoltura (MASAF): 79 DOCG, 332 DOC e 111 IGT.

Per le denominazioni con una scheda su [WikiVino](https://wikivino.it) ci sono anche il tipo di vino, i vitigni con le percentuali previste dal disciplinare, la zona di produzione e le tipologie (Riserva, Passito, Spumante...). Ogni dato delle schede è verificato sul disciplinare di produzione in vigore.

## File

- `denominazioni.csv`: una riga per denominazione
- `denominazioni.json`: gli stessi dati in JSON

| Colonna | Descrizione |
|---|---|
| nome | Nome ufficiale della denominazione |
| nomiAlternativi | Altri nomi ammessi, separati da punto e virgola |
| categoria | DOCG, DOC o IGT |
| regioni | Regione o regioni di produzione |
| province | Provincia autonoma (Bolzano o Trento), solo in Trentino-Alto Adige |
| tipo | Tipo di vino prevalente: rosso, bianco, rosato, spumante, dolce o vari |
| vitigni | Vitigni previsti dal disciplinare, con le percentuali |
| zona | Zona di produzione |
| tipologie | Tipologie previste |
| url | Pagina della scheda su WikiVino |

I conteggi aggiornati sono su [wikivino.it/quante-denominazioni](https://wikivino.it/quante-denominazioni). Come sono raccolti e verificati i dati: [wikivino.it/metodo](https://wikivino.it/metodo).
